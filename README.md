Kocaeli Üniversitesi'nde Bilgisayar Mühendisliği 3. sınıf öğrencisiyim. Şu sıralar en çok oyun geliştirme ve siber güvenlik ilgimi çekiyor; ikisinde de projeler üreterek kendimi geliştiriyorum.

- Yaz 2026'da Kocaeli Üniversitesi Akıllı Sistemler Laboratuvarı'nda **yapay zeka** stajı yaptım.
- Kocaeli Üniversitesi Bilgisayar Kulübü'nün (KOUBK) **sosyal medya ekibindeyim**.
- Projelerimin detayları ve CV'm için **[portfolyo siteme](https://ceylinacar.vercel.app)** göz atabilirsin.
